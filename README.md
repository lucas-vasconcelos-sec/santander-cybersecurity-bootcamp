## Trilha 1: Fundamentos de Linux para Cybersecurity

Nesta etapa inicial, explorei a estrutura, administração e segurança do sistema operacional Linux, focando em como utilizar a linha de comando (CLI) para gerenciar sistemas e caçar potenciais ameaças.

### Habilidades Práticas & Conceitos Dominados

#### 1. Introdução e Instalação do Sistema
* Entendimento da arquitetura do Kernel Linux e organização do sistema de arquivos (`/etc`, `/var/log`, `/bin`, `/home`).
* Configuração de ambientes controlados e laboratórios de testes através de Máquinas Virtuais.

#### 2. Acesso Remoto Seguro
* Utilização do protocolo SSH para administração remota de servidores através do terminal.
* Práticas de segurança básicas para proteger o acesso remoto e gerenciar sessões ativas.

#### 3. Manipulação de Arquivos e Análise de Logs
* Uso avançado de comandos de CLI para navegação e tratamento de dados:
  * `cd`, `ls`, `pwd` (Navegação estrutural).
  * `cat`, `less`, `head`, `tail` (Visualização rápida de arquivos de configuração e logs).
  * `grep`, `find` (Essenciais na cibersegurança para filtrar logs do sistema e caçar indicadores de comprometimento/IoCs).

#### 4. Gerenciamento de Usuários e Permissões (Princípio do Menor Privilégio)
* Criação e gerenciamento de contas e grupos no sistema através de privilégios administrativos (`sudo`).
* Controle rígido de acesso a arquivos e diretórios utilizando comandos como:
  * `chmod` (Alteração de permissões de leitura, escrita e execução).
  * `chown` (Alteração de dono e grupo de arquivos críticos).
* Aplicação prática do conceito de **IAM (Identity and Access Management)** para mitigar riscos de elevação de privilégios.
